
# Git Manager 使用手册
**#前提条必须已经安装了git**
## 一、解决了什么痛点

作为开发者，你是否遇到过这些困扰？

- **项目太多，管理混乱** —— 同时维护几十个 Git 仓库，哪个提交了、哪个没推送，完全记不清
- **重复操作，效率低下** —— 每个项目都要手动 `git add` → `git commit` → `git push`，几十个项目操作下来半天就没了
- **状态不可见** —— 不知道哪些项目有未提交的修改、哪些落后于远程，只能一个个 `git status` 查看
- **Git 报错看不懂** —— 英文错误信息一堆，不知道怎么处理
- **忘记同步** —— 下班前忘了推送代码，第二天换电脑又要折腾

**Git Manager 一站式解决以上所有问题。** 扫描目录自动发现所有仓库，一眼看清每个项目的状态，一键批量同步，再也不用担心遗漏。

## 二、功能一览

### 2.1 项目扫描与导入

- **扫描目录**：选择一个根目录，自动递归扫描（最深 3 层）发现所有 Git 仓库
- **克隆项目**：输入仓库地址 + 选择保存目录，直接克隆远程仓库并自动添加到列表
- **数据持久化**：所有项目信息保存在本地 SQLite 数据库，重启应用不丢失

### 2.2 可视化状态总览

每个项目一目了然地显示：

| 状态 | 颜色 | 含义 |
|------|------|------|
| 🔴 未提交 | 红色 | 有本地修改尚未提交 |
| 🟠 未推送 | 橙色 | 已提交但未推送到远程 |
| 🟢 已同步 | 绿色 | 与远程仓库完全同步 |
| 🔵 需拉取 | 蓝色 | 远程有新提交未拉取 |

还显示：当前分支、修改/暂存/未跟踪文件数、领先/落后提交数、最后一次提交信息。

### 2.3 单项操作

每个项目行右侧提供快捷操作按钮：

- **智能同步（魔法棒）** —— 自动判断该项目需要什么操作并执行（详见下方说明）
- **提交（铅笔）** —— 执行 `git add .` + `git commit`
- **推送（上传）** —— 执行 `git push`
- **拉取（下载）** —— 执行 `git pull`
- **更多菜单（三点）** —— 刷新状态、打开项目目录、移除项目

### 2.4 批量操作

在表格中勾选多个项目后，侧边栏支持：

- **Commit** —— 批量提交
- **Push** —— 批量推送
- **Pull** —— 批量拉取
- **Commit + Push** —— 批量提交并推送
- **智能同步** —— 批量智能同步（最推荐）

### 2.5 智能同步

**核心功能，一键搞定所有事情。** 自动根据每个项目的状态决定执行步骤：

| 项目状态 | 智能同步执行 |
|---------|-------------|
| 远程有更新 + 本地有修改 | 先拉取 → 再提交 → 再推送 |
| 远程有更新 + 本地无修改 | 仅拉取 |
| 本地有未提交修改 | 提交 + 推送 |
| 本地有未推送提交 | 仅推送 |
| 已完全同步 | 跳过 |

如果有需要提交的项目，会弹出对话框让你输入提交信息。

### 2.6 搜索与过滤

- **搜索框**：实时搜索项目名称和路径
- **状态过滤**：下拉选择只看"未提交"/"未推送"/"已同步"/"需拉取"的项目

### 2.7 收藏功能

- 点击项目行的星标图标添加收藏
- 收藏的项目显示在左侧边栏，点击可快速跳转

### 2.8 标签管理

- 为项目添加自定义标签，方便分类标记
- 点击标签的 × 可快速移除

### 2.9 操作日志

- 所有操作过程实时显示在底部日志面板
- 每一步都有详细记录（git add → git commit → git push）
- 成功绿色、失败红色、信息灰色
- 日志面板高度可拖拽调整

### 2.10 Git 错误中文翻译

遇到 Git 报错不用慌，自动翻译为中文：

```
[EasyRTMP] 失败: Permission to wujichang/repo.git denied to jiesentang.
fatal: unable to access '...' The requested URL returned error: 403

📝 权限被拒绝: 用户 jiesentang 没有仓库 wujichang/repo.git 的推送权限；
   HTTP 403 禁止访问: 没有权限，请检查仓库权限或令牌配置
```

支持 30+ 种常见错误翻译，包括认证失败、网络超时、合并冲突、权限拒绝等。

### 2.11 其他贴心功能

- **桌面通知** —— 批量操作完成后弹出系统通知
- **锁文件自动清理** —— 自动删除残留的 `.git/index.lock`，不再卡死

## 三、使用指南

### 3.1 首次使用

1. **启动应用**，等待加载完成
2. 点击左侧 **「扫描目录」** 按钮
3. 选择你存放 Git 项目的根目录（如 `F:\projects`）
4. 等待扫描完成，所有发现的 Git 仓库会自动添加到列表
5. 状态自动刷新，可以看到每个项目的实时状态

### 3.2 日常使用（推荐流程）

1. **打开应用** —— 自动加载上次的项目列表并刷新状态
2. **查看状态** —— 红色/橙色的项目需要关注
3. **全选项目** —— 点击表头的全选复选框
4. **点击「智能同步」** —— 输入提交信息，一键搞定所有同步
5. **查看日志** —— 底部日志确认每个项目的操作结果

### 3.3 克隆新项目

1. 点击左侧 **「克隆项目」** 按钮
2. 输入仓库地址（支持 HTTPS 和 SSH）
3. 点击"浏览"选择保存目录
4. 点击 **「开始克隆」**，等待完成

### 3.4 管理收藏

1. 点击项目行左侧的 **☆ 星标** 添加收藏
2. 收藏项目出现在左侧边栏
3. 点击侧边栏的收藏项目可快速定位

### 3.5 过滤查看

- 想只看有修改的项目？状态过滤选 **「未提交」**
- 想找某个项目？在搜索框输入项目名
- 搜索和过滤可以组合使用

### 3.6 处理操作失败

1. 查看底部日志面板的错误信息
2. 红色文字下方的 📝 蓝色文字是中文翻译
3. 常见问题及解决方案：
   - **推送权限拒绝** → 检查仓库权限，确认你有推送权限
   - **推送被拒绝（需先拉取）** → 使用智能同步会自动先拉取再推送
   - **认证失败** → 配置 SSH 密钥或 Git 凭据管理器
   - **网络超时** → 检查网络连接
